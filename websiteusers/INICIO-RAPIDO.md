# 🚀 Inicio Rápido - Probar la Aplicación AHORA

## Opción 1: Usar Express (Más Rápido)

### Terminal 1 - Backend:
```bash
cd backend
npm start
```

### Terminal 2 - Frontend:
```bash
cd partido-conservador-dashboard
npm start
```

### Abrir navegador:
http://localhost:4200

---

## Opción 2: Deploy a Lambda (Después del login)

### 1. Login en Serverless:
```bash
serverless login
```

### 2. Deploy:
```bash
cd backend
serverless deploy
```

### 3. Copiar URL y actualizar frontend

---
